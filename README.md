# Simple Circuits

Simple Circuits is a browser-based editor for creating and editing electrical circuit diagrams with CircuitikZ syntax. It renders a live SVG preview using TikZJax and provides controls for adding components, placing nodes, editing TeX, and exporting the result.

## Try it Out

[https://byasen.github.io/SimpleCircuits/](https://byasen.github.io/SimpleCircuits/)

## Features

- Live SVG CircuitikZ preview from the TeX editor
- Add block and directional circuit components
- Add directional, segment, and corner nodes
- Select rendered components to edit their properties
- Manual TeX editing; changes are rendered after a short typing delay
- Download the rendered circuit as an SVG file
- Progress is saved and restored automatically in your browser's `localStorage`
